## Rules & Guidelines

Before starting the exercises, please follow these important rules:

### Guidelines for Students:

1. **Read the problem carefully** - Understand what is being asked before writing code.
2. **Write clean code** - Use proper indentation and meaningful variable names.
3. **Test your solutions** - Run your code in the browser console or Node.js to verify output.
4. **Comment your code** - Add comments explaining your logic, especially for complex solutions.
5. **Follow naming conventions** - Use camelCase for variables and functions (e.g., `firstName`, `myVariable`).
6. **Use appropriate data types** - Choose the right data type for your variables.
7. **Avoid global variables** - Use local scope whenever possible.
8. **Debug systematically** - Use `console.log()` to trace your code execution.
9. **Complete all exercises** - Do not skip exercises; they build on each other.
10. **Ask for help** - If stuck, review the topic explanation or consult with instructor.

### Important Notes:

- All exercises should be completed in order.
- Create a separate JavaScript file for each exercise or group related exercises together.
- Use the `alert()`, `console.log()`, or `document.write()` methods to display results as specified.
- Save your work regularly and test in modern browsers (Chrome, Firefox, Edge).
